# Public Interview Preparation Tips Rubric

## Overview
`GET /api/interviews/public/tips` returns categorized preparation guidance for candidates before entering live simulations.

## Supported Categories
1. `BEHAVIORAL_STAR` — Situation, Task, Action, Result storytelling proportions.
2. `SYSTEM_DESIGN` — Back-of-the-envelope capacity planning, CAP trade-offs, and SPOF mitigation.
3. `TECHNICAL_CODING` — Thinking aloud, edge cases, and Big-O complexity articulation.
4. `COMMUNICATION_PACING` — Cadence, eliminating filler words, and structured wrap-ups.
5. `CLOUD_RESILIENCY` — Timeouts, idempotency keys, circuit breakers, and readiness probes.
